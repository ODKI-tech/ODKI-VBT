# Apps

The ODKI VBT companion app connects to the sensor over Bluetooth Low Energy to calibrate it, start/stop tracking, view live velocity/rep data, and install firmware updates over the air.

**License note:** the companion app is proprietary software of Lodovico Cortelazzo (ODKI). Only installable builds are published here, no app source, and it is not covered by any of the licenses in this repository ([`LICENSE`](../LICENSE)): you may install and use the published builds with your sensor, and no other license is granted (to copy, modify, redistribute or reverse-engineer them, beyond what the law allows). Terms of use for the app are still to be published. Some features (training-data management, AI-based analysis) are planned as paid add-ons — they are not available yet, and pairing and basic tracking stay free. None of this affects using the sensor itself: it speaks the openly specified [BLE protocol](../Firmware/BLE_PROTOCOL.md) (CC0), so this app or a third-party one can be used with it.

# Windows

**Status: not yet published.** Link coming soon.

Planned distribution: a downloadable installer/zip attached to this repository's GitHub Releases. Once published, this page will list the download link and setup steps. Note Windows PCs don't have built-in BLE peripheral tooling the way phones do — a Bluetooth LE-capable adapter (most modern laptops have one built in) is required.

## Usage

1. Power on the sensor (see Hardware/Instructions).
2. Open the app; pair/connect to the sensor from the device list.
3. Calibrate (hold the sensor/bar still and click Calibrate).
4. Start a set to see live velocity and rep data; each completed rep appears automatically.
5. Firmware updates, when available, are offered in-app.

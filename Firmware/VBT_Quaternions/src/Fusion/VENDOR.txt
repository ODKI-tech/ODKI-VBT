Why it is here: feasibility study of Fusion's AHRS as an alternative to the
Madgwick filter (MadgwickAHRS.cpp). It is only used when the firmware is built
with ODKI_ORIENTATION_FILTER = ODKI_ORIENTATION_FILTER_FUSION (see Config.h and
FusionOrientation.h); with the default (Madgwick) build the linker drops it and
the firmware image is byte-identical to a build without this folder.

Arduino compiles everything under the sketch's src/ folder recursively, so no
build setting is needed. To update: replace the files with those of a newer
release, update this note, and re-run tools/fusion_feasibility/.

Note on names: Fusion v1.2.x called the gyroscope bias module FusionOffset and
the rejection timeout recoveryTriggerPeriod (in samples); v1.3.x renamed them FusionBias and
rejectionTimeout (same roles).
